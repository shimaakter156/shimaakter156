### 🚀 Notable Projects

#### **Fatty Liver Clinic (FLC)**
Clinic software for 5 clinics and 10+ doctors in a Gastroenterology department, supporting a Resmetirom (MASH) study
- **Features:** digital patient record over 4 timepoints, clinical engine (BMI, FIB-4, APRI, NFS, eligibility, 30+ alert rules), patient queue with TV display, Bangla consent & diet charts, coded CSV export for SPSS
- **Tech:** Laravel 13, Vue 3, Pinia, Sanctum, Tailwind CSS, Chart.js, MySQL
- **Repo:** Private

#### **Advance Management System (AMS)**
Tracks all employee money movement for ACI Finance: requisitions, advances, adjustments, refunds and vouchers
- **Features:** multi-level checker/approver workflow, TA/DA & tour expense, ageing reports, e-statements, automated 90+ day overdue email/SMS alerts
- **Tech:** Laravel 13, Vue.js, JWT, SQL Server, 150+ API endpoints
- **Repo:** Private Enterprise

#### **HR Connect (HRMS)**
Complete HR management system leave management,Training, SEP, Gate pass management and employee evaluation
- **Tech:** Laravel, Vue.js, SQL Server
- **Scale:** 5000+ employees across multiple locations
- **Repo:** GitHub (Private Enterprise)

#### **Daily Sales Collection (DSC)**
Multi-outlet sales tracking and collection system
- **Tech:** Laravel, Vue.js, REST API, SQL Server
- **Scale:** 1000+ outlets with real-time sync
- **Repo:** GitLab (Private Enterprise)

#### **Field Force Tracker**
GPS-based real-time location tracking for field employees
- **Tech:** Vue.js, Google Maps API,REST API, WebSocket
- **Scale:** 500+ field force personnel
- **Repo:** Github (Private Enterprise)
